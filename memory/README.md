# Memory Strategy

## Objetivo

Persistir conhecimento arquitetural relevante entre sessões.

---

## Tipos de memória

### Global
Conhecimento corporativo permanente.

Exemplos:
- Sistemas core
- Vendors aprovados
- Padrões obrigatórios
- Decisões arquiteturais aprovadas

### Initiative
Memória por iniciativa/projeto.

Exemplos:
- plataforma-assinatura-digital
- middleware-corporativo
- modernização-integrações

### Domain
Memória por domínio técnico.

Exemplos:
- Integrações
- Billing
- Observabilidade
- Segurança

---

## Regras

**Nunca:**
- Salvar transcripts completos
- Salvar conteúdo irrelevante
- Misturar iniciativas
- Duplicar conhecimento

**Sempre:**
- Resumir contexto
- Salvar decisões justificadas
- Salvar riscos identificados
- Salvar integrações mapeadas
- Salvar padrões descobertos
- Referenciar ADRs relacionadas

# Presentation Rules

## Objetivo

Padronizar apresentações executivas e arquiteturais.

---

# Regras obrigatórias

Os agentes DEVEM:

1. utilizar templates oficiais
2. seguir identidade visual corporativa
3. reutilizar layouts existentes
4. seguir storytelling executivo
5. manter consistência visual
6. utilizar linguagem C-Level

# Tipos de apresentação

## Executive
- foco negócio
- impacto
- roadmap
- riscos
- decisão

---

## Architecture
- AS IS
- TO BE
- integrações
- riscos
- observabilidade

---

## Transformation
- modernização
- migração
- evolução
- fases
- timeline

---

# Storytelling obrigatório

Toda apresentação deve conter:

1. contexto
2. problema
3. impacto
4. análise
5. alternativas
6. recomendação
7. roadmap
8. próximos passos

---

# Nunca

- gerar slides genéricos
- ignorar branding
- misturar estilos
- criar apresentações sem narrativa
